One deadpan weather forecast for a city that does not exist, entered in the
[make.fun bounty](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).

`main.py` writes a single line (at most 160 characters) to `/output/entry.txt`:
a straight-faced TV forecast for Varn, where gusty 40 km/h winds are carrying
last Tuesday across the harbour, and residents are asked to return it by Friday.
